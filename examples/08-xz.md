```
OSV-scanner finding: liblzma / XZ Utils 5.6.0 and 5.6.1, CVE-2024-3094, CVSS 10.0, disclosed 29 Mar 2024.
A malicious co-maintainer, Jia Tan, hid a backdoor in the release tarballs, in a modified m4/build-to-host.m4 build macro and obfuscated test files, not in the Git repository. On systems where sshd links libsystemd, which links liblzma, the backdoor hooks RSA_public_decrypt during SSH public-key authentication, so a client with a specific Ed448 private key gets pre-authentication remote code execution. Microsoft engineer Andres Freund found it from about 500ms of extra sshd latency.
Fix: downgrade XZ Utils to an uncompromised version such as 5.4.6, or upgrade to 5.6.2.
```
